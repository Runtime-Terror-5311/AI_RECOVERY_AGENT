# Dashboard & Demo CLI

This directory contains the visualization tooling for inspecting the immutable audit trail and presenting demo narratives for the evaluation video.

## Features
- **Visual Transaction Journey:** Trace any `transaction_id` across every stage: `Ingest` → `Classify` → `Decide` → `Execute` → `Outcome`.
- **Circuit Breaker Alerts:** Highlights merchant circuit breaker events in real time.
- **Metrics Widget:** Summarizes live recovery rate and false-retry avoidance.
